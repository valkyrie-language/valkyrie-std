# API 参考

## 当前状态

本文不再维护废弃路线里的对象 API、命名空间清单或宿主运行时类图。

对当前 `valkyrie.v` 路线来说，真正稳定的不是某个历史类名，而是编译与工具链的契约边界。

## 应关注的稳定契约

### 编译输入

稳定输入应围绕这些概念组织：

- 源文件集合
- 构建配置
- `CanonicalTarget`
- 依赖闭包

### 编译输出

稳定输出应围绕这些概念组织：

- 诊断集合
- `ArtifactSet`
- 运行契约
- 调试与附属产物

### 工具链入口

稳定工具链入口应围绕这些能力组织：

- 编译
- 检查
- 格式化
- 测试
- 打包

而不是围绕某个旧的宿主运行时对象。

## 文档边界

如果后续需要补 API 参考，建议按下面三类重新写：

1. 编译契约：输入、输出、错误、目标矩阵。
2. 工具链契约：`VCC`、`Legion`、`VOA` 的命令面与交付面。
3. 扩展契约：方言、宿主绑定、family 级扩展点。

## 暂不保留的旧内容

以下内容不再作为当前路线的参考依据：

- 旧运行时对象 API
- 旧内部中间层对象暴露
- 旧命名空间和类签名清单
- 与废弃仓库路线绑定的宿主接口
