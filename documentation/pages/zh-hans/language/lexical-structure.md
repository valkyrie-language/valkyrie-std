# 词法结构

## 关键字

### 声明关键字

#### 函数声明级

| 关键字 | 说明 |
|:---|:---|
| `micro` | 轻量函数，默认选择，纯算法/短逻辑 |
| `mezzo` | 中型函数，复杂逻辑/状态管理 |
| `macro` | 宏/模板，编译期代码生成 |

#### 类型声明

| 关键字 | 说明 |
|:---|:---|
| `structure` | 不可变值类型声明 |
| `class` | 类类型声明 |
| `enums` | 枚举声明 |
| `flags` | 标志位声明 |
| `union` | 联合类型声明 |
| `unite` | 单位类型声明 |
| `trait` | 特征声明 |

#### 模块系统

| 关键字 | 说明 |
|:---|:---|
| `namespace` | 命名空间声明 |
| `using` | 引入声明 |

#### ECS/UI 扩展

| 关键字 | 说明 |
|:---|:---|
| `component` | ECS 组件声明 |
| `system` | ECS 系统声明 |
| `widget` | UI 控件声明 |

| `while` | 条件循环 |

### `let` 与 `let mut`

- `let x = expr`：不可变绑定，派生计算，赋值后不可修改
- `let mut x = expr`：可变绑定，可变状态，允许后续赋值

### `micro` / `mezzo` / `macro` 函数分级

Valkyrie 提供三级函数声明关键字，替代传统的 `fn`、`function`、`func`、`def`：

| 关键字 | 定位 | 适用场景 |
|:---|:---|:---|
| `micro` | 轻量函数，**默认选择** | 纯算法、短逻辑、无副作用的计算 |
| `mezzo` | 中型函数 | 复杂逻辑、状态管理、多步骤操作 |
| `macro` | 宏/模板 | 编译期代码生成、类型参数化展开 |

```valkyrie
micro add(a: i32, b: i32) -> i32 {
    return a + b
}

mezzo process(data: &mut Buffer) -> Result {
    ...
}

macro vec[T](items: ...T) -> Vec[T] {
    ...
}
```

## 标识符

- 以字母或下划线开头
- 后续可包含字母、数字、下划线
- 大小写敏感
- 不可与关键字冲突

## 字面量

### 布尔字面量

```
true  false
```

### 空值字面量

```
null
```

### 整数字面量

```
42          # 十进制
0xFF        # 十六进制
0o77        # 八进制
0b1010      # 二进制
1_000_000   # 下划线分隔
```

### 浮点字面量

```
3.14
1.0e10
1.0e-10
```

### 数字后缀

| 后缀 | 类型 | 示例 |
|:---|:---|:---|
| `i8` | 8 位有符号整数 | `127i8` |
| `i16` | 16 位有符号整数 | `32767i16` |
| `i32` | 32 位有符号整数 | `42i32` |
| `i64` | 64 位有符号整数 | `999999i64` |
| `u8` | 8 位无符号整数 | `255u8` |
| `u16` | 16 位无符号整数 | `65535u16` |
| `u32` | 32 位无符号整数 | `42u32` |
| `u64` | 64 位无符号整数 | `999999u64` |
| `f32` | 32 位浮点数 | `3.14f32` |
| `f64` | 64 位浮点数 | `3.14f64` |

### 字符串字面量

```valkyrie
"hello"
"你好，世界"
"line 1\nline 2"
"嵌套 {variable}"
```

## 注释

```valkyrie
# 行注释

<#
  块注释
  支持嵌套 <# 内层注释 #>
#>
```

- 行注释以 `#` 开头，到行尾结束
- 块注释以 `<#` 开头，`#>` 结尾，支持嵌套

## 元代码块

```valkyrie
<% if condition %>
    ...
<% end %>

<% expr %>
```

元代码块用于编译期代码生成和模板渲染，详见 [Template 扩展](extensions/template-extension.md)。
