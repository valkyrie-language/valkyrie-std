# 词法结构

本文档与 IntelliJ Valkyrie 插件词法分析器（`ValkyrieLexer` / `ValkyrieTypes`）保持双向同步。

## 关键字

### 声明关键字

#### 函数声明级

| 关键字 | 说明 |
|:---|:---|
| `micro` | 轻量函数，默认选择，纯算法/短逻辑 |
| `mezzo` | 中型函数，复杂逻辑/状态管理 |
| `macro` | 宏/模板，编译期代码生成 |

#### 类型声明

| 关键字 | 说明 |
|:---|:---|
| `structure` | 不可变值类型声明 |
| `class` | 类类型声明 |
| `enums` / `eidos` | 枚举声明 |
| `flags` | 标志位声明 |
| `union` | 联合类型声明 |
| `unite` | 代数数据类型（封闭 variant 族） |
| `trait` | 特征声明 |

> **`unity` 已废弃**，请统一使用 `unite`。`unity` 不是语言关键字。

> **`extern` 与 `unsafe` 不存在**——Valkyrie 不提供这两个关键字。FFI 与底层指针通过修饰符、后缀解引用（`.◇` / `.◆`）及效应系统表达，而非独立的 `extern` / `unsafe` 块。

#### 模块系统

| 关键字 | 说明 |
|:---|:---|
| `namespace` | 命名空间声明 |
| `using` | 引入声明 |

#### ECS/UI 扩展

| 关键字 | 说明 |
|:---|:---|
| `component` | ECS 组件声明 |
| `system` | ECS 系统声明 |
| `widget` | UI 控件声明 |

#### 其他

| 关键字 | 说明 |
|:---|:---|
| `let` | 不可变绑定 |
| `let mut` | 可变绑定 |
| `where` | 泛型约束 |
| `imply` | trait 显式满足声明 |

### 语句关键字

| 关键字 | 说明 |
|:---|:---|
| `if` / `else` | 条件分支 |
| `while` | 条件循环 |
| `until` | 直到循环 |
| `loop` | 循环 |
| `match` | 模式匹配 |
| `case` | 匹配分支 |
| `when` | 守卫条件 |
| `catch` | 效应捕获 |
| `type` | 类型别名 |
| `return` | 返回 |
| `resume` | 恢复执行 |
| `break` | 跳出循环 |
| `continue` | 继续下一次循环 |
| `end` | 模板块闭合（仅模板模式） |
| `in` | 遍历 |
| `is` | 类型检查 |
| `as` | 类型转换 |

### `let` 与 `let mut`

- `let x = expr`：不可变绑定，派生计算，赋值后不可修改
- `let mut x = expr`：可变绑定，可变状态，允许后续赋值

### `micro` / `mezzo` / `macro` 函数分级

Valkyrie 提供三级函数声明关键字，替代传统的 `fn`、`function`、`func`、`def`：

| 关键字 | 定位 | 适用场景 |
|:---|:---|:---|
| `micro` | 轻量函数，**默认选择** | 纯算法、短逻辑、无副作用的计算 |
| `mezzo` | 中型函数 | 复杂逻辑、状态管理、多步骤操作 |
| `macro` | 宏/模板 | 编译期代码生成、类型参数化展开 |

```valkyrie
micro add(a: i32, b: i32) -> i32 {
    return a + b
}

mezzo process(data: &mut Buffer) -> Result {
    ...
}

macro vec[T](items: ...T) -> Vec[T] {
    ...
}
```

## 标识符

- 以字母或下划线开头
- 后续可包含字母、数字、下划线
- 大小写敏感
- 不可与关键字冲突

## 字面量

### 布尔字面量

```
true  false
```

### 空值字面量

```
null  nil
```

### 整数字面量

```
42          # 十进制
0xFF        # 十六进制
0o77        # 八进制
0b1010      # 二进制
1_000_000   # 下划线分隔
```

### 浮点字面量

```
3.14
1.0e10
1.0e-10
```

### 数字后缀

| 后缀 | 类型 | 示例 |
|:---|:---|:---|
| `i8` | 8 位有符号整数 | `127i8` |
| `i16` | 16 位有符号整数 | `32767i16` |
| `i32` | 32 位有符号整数 | `42i32` |
| `i64` | 64 位有符号整数 | `999999i64` |
| `u8` | 8 位无符号整数 | `255u8` |
| `u16` | 16 位无符号整数 | `65535u16` |
| `u32` | 32 位无符号整数 | `42u32` |
| `u64` | 64 位无符号整数 | `999999u64` |
| `f32` | 32 位浮点数 | `3.14f32` |
| `f64` | 64 位浮点数 | `3.14f64` |

### 数字宏（MACRO_NUMBER / MACRO_STRING）

标识符紧跟数字或字符串时，词法层识别为宏字面量：

```valkyrie
10mm          # MACRO_NUMBER：带单位/宏后缀的数值
42px
1.5rem
id"foo"       # MACRO_STRING：带前缀的宏字符串
key"value"
```

- **MACRO_NUMBER**：数字字面量后紧跟标识符（如 `10mm`、`3.14rem`）
- **MACRO_STRING**：标识符后紧跟字符串（如 `id"foo"`、`url"https://..."`）

### 字符串字面量

```valkyrie
"hello"
"你好，世界"
"line 1\nline 2"
"嵌套 {variable}"
"表达式 {slot + 1}"
r"{slot}"
```

普通双引号字符串支持转义与插值。

- 花括号内允许放入表达式，并按普通表达式语法解析，例如成员访问、调用和二元运算都可以出现在插值段中
- `\n`、`\t`、`\"` 这类转义序列在普通字符串中生效
- `r"..."` 是 raw string，不进行转义，也不进行插值，因此 `r"{slot}"` 的内容就是字面文本 `{slot}`

## 泛型参数

| 形式 | 说明 |
|:---|:---|
| `⟨T⟩` | **规范写法**（U+27E8 / U+27E9） |
| `<T>` | ASCII 兼容 |
| `::<T>` | 作用域解析 + ASCII 角括号兼容 |

```valkyrie
micro identity⟨T⟩(value: T) -> T { value }
micro map<T, U>(items: [T]) -> [U] { ... }
Option::<i32>
```

## 分隔符

| 分隔符 | 说明 |
|:---|:---|
| `(` `)` | 分组、参数列表 |
| `[` `]` | 列表、索引、特性标注 |
| `{` `}` | 代码块 |
| `,` | 逗号分隔 |
| `.` | 成员访问 |
| `⸬` | **规范**限定名分隔（如 `Option⸬Some`） |
| `::` | ASCII 兼容限定名分隔 |
| `:` | 类型标注 |
| `;` | 语句终止（可选） |

```valkyrie
imply Option⟨V⟩⸬Some { ... }
Flags⸬A | Flags⸬C
namespace game::physics { ... }   # :: 兼容写法
```

## 标签（※）

`※` 是控制流标签的规范标记（`@*` 为兼容别名）：

```valkyrie
loop ※outer {
    loop ※inner {
        if done { break ※outer }
        continue ※inner
    }
}

while condition ※search {
    if found { break ※search }
}

return ※label value
```

可用于 `loop`、`while`、`until`、`for ... in`、`break`、`continue`、`return`、`raise`、`resume`、`yield`、`fallthrough` 等语句。

## 注释

```valkyrie
# 行注释

<#
  块注释
  支持嵌套 <# 内层注释 #>
#>
```

- 行注释以 `#` 开头，到行尾结束
- 块注释以 `<#` 开头，`#>` 结尾，支持嵌套

## 元代码块

```valkyrie
<% if condition %>

<% end %>

```
