# `demo.wechat.game`

微信小游戏构建流示例。

## 目标

- 由腾讯自己的第三方构建器隐式注入 `tencent.wechat.sdk`
- 使用 `std` 的统一入口
- 编译阶段只负责生成微信小游戏可消费的中间产物
- 最终构建与发布交给腾讯自己的独立构建工具

## 构建流

1. `vcc` 编译 `Valkyrie` 源码
2. 输出目录写入 `build/wechat`
3. 腾讯维护的微信小游戏构建工具读取这些产物
4. 该工具处理小游戏工程组织、配置、资源与打包问题
5. 预览、上传、发布继续由腾讯工具链负责

## 边界

- 项目通常不需要显式写 `tencent.wechat.sdk`
- 只有锁版本、测试版本或覆盖默认实现时才显式写出 `sdk` 依赖
- `legion` 不负责微信小游戏最终打包
- 微信小游戏后续构建工具不是 `legion` 插件
- 该工具只是共享 `nyar` 的基础 build 体系
