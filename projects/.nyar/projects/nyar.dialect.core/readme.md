# nyar.dialect.core

`nyar.dialect.core` 是 `nyar` 体系中的核心方言层，面向裸金属开发。

## 定位

- 面向裸金属与低级系统开发
- 提供尽可能小而稳定的基础能力面
- 为更高层方言提供最底层语义基座

## 适合承载什么

- 低级控制流与数据操作
- 显式内存与布局相关能力
- 对宿主运行时依赖尽可能弱的基础抽象
- 靠近硬件或底层平台的开发模型

## 不适合承载什么

- `GC` 等高级运行时假设
- 浏览器或前端宿主模型
- 依赖大型托管运行时的高层对象语义

## 与其他方言的关系

- `nyar.dialect.core`：裸金属与最小能力面
- `nyar.dialect.standard`：在此之上提供带高级运行时的能力
- `nyar.dialect.web`：在此之上提供面向前端的能力

## 目标

- 让底层开发可以不被高级运行时绑定
- 保持最小核心方言的长期稳定
- 避免把高层场景需求反向污染到底层
