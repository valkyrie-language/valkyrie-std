# nyar.dialect.standard

`nyar.dialect.standard` 是 `nyar` 体系中的标准方言层，面向带高级运行时能力的开发。

## 定位

- 建立在 `nyar.dialect.core` 之上
- 提供带 `GC` 等高级运行时支持的能力面
- 面向更完整的应用开发与托管执行环境

## 适合承载什么

- `GC` 友好的对象与资源模型
- 更完整的高级运行时服务
- 对开发体验更友好的高层抽象
- 依赖标准运行时支持的通用应用能力

## 不适合承载什么

- 裸金属最小核心语义
- 浏览器专属或前端专属能力
- 把所有场景都混进来的统一大方言

## 与其他方言的关系

- `nyar.dialect.core`：提供最小核心能力面
- `nyar.dialect.standard`：提供高级运行时语义
- `nyar.dialect.web`：提供前端与浏览器相关能力

## 目标

- 让高级运行时能力有清晰归属
- 避免把 `GC` 等假设抬升为所有方言的公共前提
- 为应用层开发提供稳定的标准方言基础
