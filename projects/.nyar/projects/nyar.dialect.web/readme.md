# nyar.dialect.web

`nyar.dialect.web` 是 `nyar` 体系中的前端方言层，主要专注于 `web` 开发。

## 定位

- 面向前端与浏览器场景
- 建立在更底层方言能力之上
- 提供适合页面、交互和前端宿主的语义面

## 适合承载什么

- 前端页面与交互相关能力
- 浏览器宿主模型与前端开发语义
- 面向 `web` 的组件、资源与运行边界
- 服务端到客户端分工中的前端侧能力

## 不适合承载什么

- 裸金属基础能力定义
- `GC` 等通用高级运行时核心职责
- 把前端宿主细节反向抬升成所有方言的公共前提

## 与其他方言的关系

- `nyar.dialect.core`：提供底层最小能力面
- `nyar.dialect.standard`：提供高级运行时能力
- `nyar.dialect.web`：提供前端专用能力与开发模型

## 目标

- 让前端能力有独立、清晰的归属
- 避免浏览器需求污染通用方言边界
- 为 `web` 场景保留可持续扩展的方言空间
