# nyar.language

`nyar.language` 负责 `nyar` 体系中的各种语言前端分析。

## 定位

- 面向多语言前端与前端分析流程
- 承载解析、语义建模、前端约束检查等工作
- 作为不同语言接入 `nyar` 体系的前端入口层

## 适合承载什么

- 各种语言的解析与前端分析
- 语言级名称、语法、语义与前端约束
- 前端阶段的诊断、绑定与分析结果
- 多语言接入时共享的前端组织方式

## 不适合承载什么

- `nyar` 核心公共协议本身
- 运行时家族的专用实现细节
- 包管理器与注册表流程
- 把具体语言私货直接抬升成核心层公共前提

## 与其他项目的关系

- `nyar`：提供核心公共基座
- `nyar.language`：承接各种语言前端分析
- `nyar.package_manager` 与 `nyar.package_registry`：位于生态与交付层

## 目标

- 让多语言前端有明确归属
- 保持前端分析与核心公共层分离
- 避免前端语义直接污染运行时、包管理或核心基础设施
