# nyar.vm.clr

`nyar.vm.clr` 是 `nyar` 体系中的 `CLR` 经典运行时家族文档入口。

## 定位

- 面向 `CLR` / `.NET` 宿主环境
- 基于 `nyar` 公共基础设施实现 `CLR` 运行时家族
- 负责 `CLR` 家族特有的入口、宿主契约、运行模型与交付约定

## 关注点

- `CLR` 目标的运行时行为
- 托管宿主入口约定
- 调试资产、sidecar 与运行契约
- 与其他经典运行时家族共享的公共基础设施边界

## 不负责什么

- 不定义具体语言的前端语义
- 不承担通用 `HIR / MIR` 语义分析职责
- 不替其他 target family 设计统一低层模型

## 与其他项目的关系

- `projects/nyar`：提供公共 target 与契约基础设施
- 与 `nyar.vm.jvm`、`nyar.vm.wasm` 一起组成基于 `nyar` 基础设施的经典运行时家族

## 说明

当前目录主要作为 `nyar.vm.clr` 的项目说明入口，后续可以继续细化：

- 运行时契约
- 入口规则
- 宿主依赖
- 调试与交付规范
