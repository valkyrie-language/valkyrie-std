# nyar.vm.nyar_vm

`nyar.vm.nyar_vm` 是 `Nyar` 原生指令集运行时文档入口。

## 定位

- 面向 `Nyar` 原生指令集
- 作为 `nyar` 体系中的专用高性能 VM 路线
- 重点服务 `ECS` 等系统场景
- 允许围绕原生执行模型做更激进的数据与调度优化

## 核心目标

- 提供稳定的原生指令集执行环境
- 为系统编程场景保留高性能优化空间
- 针对 `ECS`、批量调度、数据局部性等需求做专门设计
- 保持与通用多语言 runtime 的职责分离

## 可能关注的优化方向

- 数据布局优化
- 组件访问与批量遍历
- 调度与任务分发
- 内存模型与缓存友好设计
- 原生调试与性能分析支持

## 不负责什么

- 不承担多语言脚本兼容的万能 runtime 职责
- 不回退成面向所有宿主的统一兼容壳
- 不把 `Nyar` 专属假设反向污染到公共基础层

## 与 `nyar.vm.legacy_vm` 的区别

- `nyar_vm` 面向 `Nyar` 原生执行模型与系统级优化
- `legacy_vm` 面向多语言脚本与通用运行时承载
