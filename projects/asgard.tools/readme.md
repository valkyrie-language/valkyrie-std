# asgard.tools

`asgard.tools` 是 `Asgard` 全站框架的命令行工具项目。

## 定位

- 面向 `Asgard` 框架的 `CLI`
- 作为 `Asgard` 工程的创建、构建与开发入口
- 承载全站框架相关的工具链工作流

## 适合承载什么

- `Asgard` 项目初始化与脚手架
- 开发、构建、调试与发布命令
- 全站框架工程约定与本地开发工作流
- 面向 `Asgard` 用户的命令行交互

## 不适合承载什么

- `nyar` 核心公共协议
- 通用语言前端分析
- 与 `Asgard` 无关的包管理核心能力
- 其他框架或运行时家族的专用工具逻辑

## 与其他项目的关系

- 基于 `nyar` 体系的公共基础设施
- 与 `atlas.tools`、`legend.tools`、`legion.tools` 同属工具项目
- 各个工具之间职责独立，不互相从属
- `asgard.tools` 只负责 `Asgard` 的工具入口

## 目标

- 让 `Asgard` 有独立、清晰的工具入口
- 避免框架级工具逻辑回流污染核心库
- 为全站框架提供稳定的开发体验
