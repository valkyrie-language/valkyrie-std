# nyar.package_registry

`nyar.package_registry` 负责 `nyar` 体系中的包注册表能力。

## 定位

- 面向包发布、索引、查询与分发
- 承载注册表侧的服务职责与生态能力
- 作为包管理体系中的注册表一侧

## 适合承载什么

- 包索引与元数据管理
- 发布与分发协议
- 查询、检索与可发现性能力
- 面向生态系统的注册表规则与服务接口

## 不适合承载什么

- 本地包管理客户端流程
- 语言前端分析与编译核心
- 单一运行时家族的私有实现
- 把注册表业务规则反向提升成核心公共协议

## 与其他项目的关系

- `nyar`：提供核心公共部分
- `nyar.language`：负责语言前端分析
- `nyar.package_manager`：负责包管理客户端与工程流程
- `nyar.package_registry`：负责注册表服务与生态分发

## 目标

- 让注册表职责保持独立
- 避免服务端生态逻辑污染核心层与前端层
- 为整个 `nyar` 生态提供稳定的发布与分发基础
