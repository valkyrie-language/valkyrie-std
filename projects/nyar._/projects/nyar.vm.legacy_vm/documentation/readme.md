# nyar.vm.legacy_vm

`nyar.vm.legacy_vm` 定位为基于 `PE` 的万能运行时。

## 定位

- 作为多语言承载运行时，而不是只服务单一语言
- 先覆盖 `bash`、`powershell`、`tcl`
- 后续继续扩展到 `typescript`、`python`
- 通过统一的运行时能力面承接不同脚本语言或胶水语言

## 核心目标

- 为多语言脚本提供统一运行时宿主
- 通过 `PE` 承接通用执行模型
- 提供稳定的运行契约、调试入口与交付边界
- 避免把任意单一语言的前端语义抬升成公共基础层

## 适合承接的能力

- 进程与命令执行
- 管道与文本流
- 文件系统与环境变量
- 动态模块装载
- 宿主脚本互操作

## 不负责什么

- 不承担 `valkyrie.v` 专属前端语义
- 不等同于 `Nyar` 原生指令集运行时
- 不把所有目标家族重新揉成统一大 `IR`

## 与 `nyar.vm.nyar_vm` 的区别

- `legacy_vm` 追求多语言兼容与通用运行时能力
- `nyar_vm` 追求 `Nyar` 原生指令集与系统级特化优化
