# nyar.package_manager

`nyar.package_manager` 负责 `nyar` 体系中的包管理能力。

## 定位

- 面向依赖管理、安装、解析与本地包流程
- 承载包管理器相关的业务逻辑
- 作为工程与生态层的重要组成部分

## 适合承载什么

- 包依赖解析
- 安装、更新与移除流程
- 本地缓存、锁文件与工作区管理
- 面向开发者的包管理操作与策略

## 不适合承载什么

- 核心编译语义与语言前端分析
- 注册表服务端职责
- 单一运行时家族的私有实现
- 反向定义 `nyar` 核心公共协议

## 与其他项目的关系

- `nyar`：提供核心公共部分
- `nyar.language`：负责语言前端分析
- `nyar.package_manager`：负责包管理客户端与工程流程
- `nyar.package_registry`：负责包注册表能力

## 目标

- 让包管理职责独立清晰
- 避免包管理逻辑侵入核心编译与运行时层
- 为整个生态提供稳定的工程入口
