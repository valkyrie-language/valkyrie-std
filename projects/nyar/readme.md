# nyar

`nyar` 是整个 `nyar` 体系的核心层，承载所有公共基础设施与共享抽象。

## 定位

- 作为整个体系的核心公共部分
- 提供稳定、可复用的基础协议与核心类型
- 为运行时、方言、语言前端、包管理和交付系统提供共同基座

## 适合承载什么

- 核心公共类型与基础结构
- 目标身份、运行契约、交付契约等共享协议
- 不依赖具体语言前端的公共抽象
- 不偏向单一运行时或单一宿主的基础设施

## 不适合承载什么

- 具体语言前端分析逻辑
- 单一 VM 或单一宿主的专用运行时细节
- 包管理器或注册表的业务流程
- 只为某个方言或某个 family 服务的私有假设

## 与其他项目的关系

- `nyar`：核心公共部分
- `nyar.language`：各种语言前端分析
- `nyar.package_manager`：包管理能力
- `nyar.package_registry`：包注册表能力

## 目标

- 保持核心边界稳定
- 避免语言私货、运行时私货和生态层私货反向污染核心
- 为整个 `nyar` 体系提供长期可维护的公共基座
